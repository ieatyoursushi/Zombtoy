# ADR-001: Focused solo game and backend learning sandbox

**Status:** Accepted · **Recorded:** 2026-10-30

## Context
The project accumulated speculative infrastructure before its single-player loop was finished.

## Decision
Prioritize a playable single-player game. Keep the small .NET backend as a learning project. Multiplayer is not near-term.

## Consequences
Do not treat framework size as progress. The Titan remains scene-placed; boss activation polish belongs to M6.

## Reconsider when
A team, publishing plan, or explicit multiplayer commitment changes the product requirements.
